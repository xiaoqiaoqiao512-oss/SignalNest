# 申请主体与历史阶段修复：政策 v9

源码规则已从 v8 升至 v9；生产实例仍执行 v8。本说明保留规则设计和验证边界，不包含原公告正文、来源身份或逐条评估快照。详细原件保留在本地研究记录中。

## 修复范围

离线复核发现，已完成的教师选题征集和面向学生的后续项目申报可能被误认为同一申请阶段；指导教师和受益学生也可能被误判为申请人。v9按局部声明区分申请人、受益者和历史阶段：

- 已完成的教师征题不直接成为学生申报的教师资格限制。
- “面向本科生、在指导教师指导下”等受益者描述，不单独表示申请人是教师。
- 明确的负责人资格可以形成约束；毕业年级、团队人数、成员互斥和导师条件继续要求核对。
- 否定、OR、例外或无法区分范围的并列主体保留为未知，不静默选择其中一个。
- 只有月份、年份缺失或阶段不明确时，不推导精确截止日期或开放状态。

这些规则是有限文本模板，不是通用中文语义理解；未知条件不代表符合资格。
